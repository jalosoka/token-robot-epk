What is Token Robot?

Nighttime Psychedelic from Switzerland

Token Robot is a Nighttime Psychedelic project from Switzerland, delivering robotic funk, deep psychedelic grooves and good vibes for psychedelic dancefloors.

The project combines machine-like movement, playful sound design and high-quality original production - written for night-time psychedelic floors, but colorful enough to move different dancefloors.
